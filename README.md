# midtermApp

This is a basic Node.js app built with Express and Handlebars.

## Tools Used

- [Node.js]

## How to use

1. Unzip the package and open a Git BASH(or your favorite terminal) in the folder location.
2. Install the necessary dependencies:

   ```bash
   npm install
   ```

3. Start the server:

   ```bash
   node app.js
   ```

4. Open <http://localhost:3000> in your browser.

Press `Ctrl-C` to stop the server.
